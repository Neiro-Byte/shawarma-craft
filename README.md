# SHAWARMA CRAFT 3D

Мобильный конструктор шаурмы и локальная очередь для кухни. Покупатель собирает до трёх шаурм, выбирает дополнения и отправляет заказ. Сотрудник видит состав, гриль и заданную покупателем последовательность начинок.

## Что можно попробовать

- Собрать шаурму нажатием на ингредиенты в меню или на 3D-полках. Соус наливается из бутылочки, курица срезается с вертела.
- Включить «Важен порядок начинки» для отдельной шаурмы, переставить шаги и проверить их в корзине.
- Оформить заказ из мобильной корзины с 3D-анимацией или в быстром режиме.
- Открыть экран кухни, принять состав и перевести заказ из «Принят» в «Готовится», затем в «Готов». Покупатель видит номер и статус.

## Публичная демонстрация

[Открыть SHAWARMA CRAFT](https://neiro-byte.github.io/shawarma-craft/)

Витрина работает на GitHub Pages без входа и запущенного компьютера. Можно проверить 3D, звук и оформление демо-заказа. Состав сохраняется в браузере посетителя. Для очереди кухни и общего меню используйте серверную установку ниже.

## Открыть в браузере через GitHub

[Открыть в GitHub Codespaces](https://codespaces.new/Neiro-Byte/shawarma-craft?quickstart=1)

В репозитории выберите **Code → Codespaces → Create codespace on main**. GitHub установит зависимости на своём сервере и откроет приложение. Если предпросмотр не появился, в Codespaces откройте **Ports → SHAWARMA CRAFT 3D → Open in Browser**. Сохраняйте для порта режим **Private**. Компьютер с локальной копией проекта может быть выключен.

Облачный запуск использует отдельный демонстрационный каталог. Для проверки кухни задайте отдельный код в секрете Codespaces с именем `SHAWARMA_STAFF_PIN` и перезапустите Codespace. База заказов из локальной установки при этом не переносится.

## Запуск на компьютере

Для запуска используйте Node.js 24 и npm.

```sh
npm install
npm run dev
```

Откройте `http://localhost:5173/`. Без настроенного кода сотрудника доступен демонстрационный заказ в браузере. Для локального пилота задайте в окружении процесса переменную `SHAWARMA_STAFF_PIN` со своим кодом. Перезапустите приложение, откройте `http://localhost:5173/#kitchen` и войдите. Управление общим меню и ценами доступно в этом браузере после входа. По умолчанию база SQLite находится в `.shawarma-local/`.

```sh
npm run check
node server/check-kitchen-api.mjs
npm run build
npm run preview
```

## Как устроен проект

- **Интерфейс** — React, TypeScript и Vite. В корзине владелец каждого заказа видит свой статус по отдельному идентификатору.
- **3D** — Three.js, React Three Fiber, Drei и GSAP. Модели и текстуры создаются процедурно. На телефоне сцена загружается при открытии или запуске готовки.
- **Заказы** — локальный API и SQLite. Сервер проверяет наличие и пересчитывает цену. Уникальный идентификатор запроса защищает от дублей при повторной отправке.
- **Доступ сотрудника** — код из окружения, ограничение попыток входа и сессия с HttpOnly-cookie. Очередь кухни и запись общего меню требуют входа.

## Резервная копия кухни

После первого сохранения меню или заказа выполните `npm run backup:kitchen`. Команда создаёт согласованную копию SQLite в `.shawarma-local/backups/`, включая изменения работающего сервера. Для собственного каталога данных используется `SHAWARMA_KITCHEN_DATA_DIR`.

Копия проверяется на целостность и читаемость таблиц меню и заказов. Чтобы проверить её отдельно, задайте `SHAWARMA_KITCHEN_DATA_DIR` на новую папку, поместите туда копию под именем `kitchen.sqlite` и запустите отдельный экземпляр приложения. Перед восстановлением основной установки остановите сервер и сохраните её текущее состояние. Локальные копии защищают от ошибочных изменений, для защиты от потери устройства храните копию также на отдельном носителе.

## Границы пилота

Демонстрационные рецепты и цены. Для работы за пределами доверенной локальной сети потребуются HTTPS и отдельный производственный запуск. Оплата и интеграция с кассой пока не подключены.
