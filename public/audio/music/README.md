# Quiet Bazaar

Оригинальная спокойная инструментальная композиция для SHAWARMA CRAFT. Написана и синтезирована специально для проекта. Внешние музыкальные записи, готовые лупы, сэмплы и заимствованные мелодии не использовались. Отдельных требований сторонних музыкальных правообладателей у этого файла нет; применяются условия самого проекта.

72 BPM, 16 тактов, размер 4/4, около 53,33 секунды. Основа — мягкие аккорды электрического пианино, тёплый бас, тихий ритм с небольшим свингом и редкие щипковые ноты, напоминающие уд. Тональная основа — ре минор, с осторожными гармоническими оборотами C♯–D для лёгкого восточного оттенка. Голоса и звуки приготовления в музыку не включены.

Хвосты нот и отражений сведены через границу цикла. MP3 содержит метаданные задержки кодировщика, а декодированный звук проверен на сохранение длительности и отсутствие большого скачка на границе. Непрерывность повтора в конкретном мобильном браузере ещё нужно оценить на слух.

Файл `quiet-bazaar-v1.mp3` — стерео, 32 кГц, 96 кбит/с, 641 132 байта. Нормализация ориентирована на −22 LUFS, итоговое измерение близко к −22,8 LUFS; измеренный истинный пик составляет около −6,6 dBFS. Для финального файла отдельно проверен декодированный выборочный пик ниже −3 dBFS. В приложении рекомендуется тихий уровень около 0,35, чтобы звуки продуктов оставались впереди.

Воспроизводимый генератор — `scripts/render-lofi.py` в корне проекта. Зависимости для повторного рендера — Python, NumPy и FFmpeg. Никакой синтез музыки на телефоне не выполняется: браузер воспроизводит готовый файл.

Численные проверки пройдены; субъективное прослушивание на телефоне и в наушниках не подтверждено. Контрольная сумма и характеристики находятся в `manifest.json`.
